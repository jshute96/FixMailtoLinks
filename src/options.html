Fix Mailto Links — Options

This extension redirects mailto: links to chosen target sites, or opens a dialog box where you can pick.

Target sites

Email domain Link target URL Open
directly Rearrange

No targets — every mailto: link will open the dialog.

Rules

  • Email domain:
    • abc.com — that domain and its subdomains
    • empty — match any address
  • Link target URL:
    • Target URL, which includes a {username} or {email} substitution
  • Targets are checked top to bottom.
  • The first match with open directly is opened.
  • If none open directly, a dialog box shows all matching links.

Test it
